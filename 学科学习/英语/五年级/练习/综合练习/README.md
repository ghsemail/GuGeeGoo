## 生成 PDF

在仓库根目录：

```bash
npm run pdf -- 学科学习/英语/五年级/练习/综合练习/综合练习-第1单元.md --answers 综合练习-第1单元-答案.md --out 学科学习/英语/五年级/练习/综合练习
npm run pdf -- 学科学习/英语/五年级/练习/综合练习/综合练习-第2单元.md --answers 综合练习-第2单元-答案.md --out 学科学习/英语/五年级/练习/综合练习
npm run pdf -- 学科学习/英语/五年级/练习/综合练习/综合练习-第1-2单元.md --answers 综合练习-第1-2单元-答案.md --out 学科学习/英语/五年级/练习/综合练习

（`--answers` 为答案文件名，相对练习 MD 所在目录；`--out` 使 PDF 与 MD 同目录。）
```

或：`cd 学科学习/英语/五年级/练习/脚本 && npm run comprehensive`
