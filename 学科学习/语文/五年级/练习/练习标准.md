## 1. 练习材料类型

| 类型 | 命名（PDF，与源 MD 同名） | 说明 |
|------|---------------------------|------|
| 四天巩固 | `第N单元-四天巩固.pdf` + `第N单元-四天巩固-答案.pdf` | 4 页练习，答案合订不分页 |
| Memo | `第N单元-复习备忘.pdf` | 易错点备忘，课后看 |
| 单元小测 | `第N单元-单元小测.pdf` + `第N单元-单元小测-答案.pdf` | 整单元短测（约 5～8 题） |
| 薄弱点回顾训练 | `第N单元-薄弱点回顾训练.pdf` + `-答案.pdf` | 针对档案薄弱点 |

### 源文件（`练习/源文件/`）

- `第N单元-四天巩固-第1天.md` … `第4天.md`
- `第N单元-四天巩固-答案.md`
- `第N单元-单元小测.md` + `-答案.md`
- `第N单元-薄弱点回顾训练.md` + `-答案.md`
- `第N单元-练习索引.md`
- `第N单元-复习备忘.md`（Memo 源文件）

## 2. 题量与字号

| 类型 | 题量 | 字号 | 备注 |
|------|------|------|------|
| 每日巩固练 | 7–10 题 | 17–20px | A4 每日一页 |
| 单元小测 | 5–8 题 | 20px+ | 聚焦 1–2 个薄弱点 |
| 复习备忘 | — | — | 单页卡片式 |
| 薄弱点回顾 | — | 可大字 | 针对档案薄弱点 |

## 3. 题型说明

### 字词基础

- 看拼音写词语
- 形近字辨析
- 多音字选择
- 词语搭配
- 成语填空

### 古诗文

- 古诗默写
- 诗句理解
- 名句填空
- 作者与朝代匹配

### 阅读理解

- 短文阅读
- 段落大意
- 修辞手法辨析
- 关键词句理解

### 作文

- 小练笔（50-100 字）
- 素材积累
- 结构训练

## 4. 卷面格式

### 练习卷

| 项目 | 格式 |
|------|------|
| 标题 | 「第 X 单元 主题名 巩固练习」 |
| 内部序号 | **不带**（不写「练习 1」「练习 2」） |
| 副标题行 | 左「顾景源 · 五年级语文 · 部编版」，右「日期：________」 |
| 姓名栏 | **不要** |
| 书写空间 | 汉字书写题留足空间 |

### 答案卷

| 项目 | 格式 |
|------|------|
| 标注 | 「家长专用」 |
| 日期栏 | **无** |
| 解析 | 含详细解析和易错提醒 |

### 学生可见内容禁止包含

- WP-Cxxx / MP-Cxxx 编码
- 知识点标签
- 内部来源标注

### 输出格式

**只用 MD + PDF，绝不输出 HTML**
