### WP-M002 比例多条件综合题（倒数+比值+内项积=外项积）

| 项目 | 内容 |
|------|------|
| 关联讲次 | 第 1 讲 · 比和比例 |
| 首次发现 | 2026-09-26 · 第 1 讲 Day 1 Q3（⭐难题） |
| 典型错题 | 「前两项互为倒数，比值为4，内项积为4，求两个外项之和」 |
| 正确答案 | **4**（比例式 2:1/2 = 8:2，外项 2+2=4） |
| 解题思路 | ①前两项互为倒数且比值=4 → 设 a:1/a=4:1 → a²=4 → a=2 → 前两项 2:1/2<br>②内项积=4 → 1/2 × 内项2 = 4 → 内项2=8<br>③比值=4 → 8÷外项2=4 → 外项2=2<br>④外项之和=2+2=4 |
| 关联知识 | 比例的基本性质、互为倒数、比值定义 |
| 状态 | **薄弱** |
| 巩固记录 | 2026-09-26 首次发现；订正草稿已推导出 2:1/2=8:2 |

**掌握标准：** 比例多条件综合题连续 2 次全对。
