# GuGeeGoo — 顾景源的 AI 学习项目

这是为顾景源小朋友设计的 AI 学习项目，由家长规划内容、准备材料，景源以观看、互动、动手改参数等方式学习。

## 目录说明

| 目录 | 用途 |
|------|------|
| `planning/` | 家长端：教案、路线图、进度记录 |
| `materials/` | 给景源看的学习材料（课程、练习、打印件） |
| `code/` | 演示程序、可玩可改版、小工具 |
| `assets/` | 插图、模板等素材 |

## 使用方式

1. 在 `planning/roadmap.md` 查看学习路线
2. 按 `planning/lesson-plans/` 中的教案准备每节课
3. 将整理好的内容放入 `materials/`，代码放入 `code/`
4. 在 `planning/progress.md` 记录景源的学习进度
