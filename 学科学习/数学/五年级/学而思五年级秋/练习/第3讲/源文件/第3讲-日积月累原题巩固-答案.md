## 第 1 题　（第3讲-大开眼界-1）

**答：$24$**

解析：

- **分母：** $(1+3+5+7+9) \times 20 + 3 = 25 \times 20 + 3 = 503$
- **分子第一项：** $3\frac{3}{4} = \frac{15}{4}$；$\frac{15}{4} \times 1.3 = \frac{15}{4} \times \frac{13}{10} = \frac{39}{8}$
- **分子第二项：** $3 \div 2\frac{2}{3} = 3 \div \frac{8}{3} = 3 \times \frac{3}{8} = \frac{9}{8}$
- **分子之和：** $\frac{39}{8} + \frac{9}{8} = \frac{48}{8} = 6$
- **总式：** $2012 \times \frac{6}{503}$；$2012 \div 503 = 4$，故 $4 \times 6 =$ **24**

### 易错提醒

- $1.3$ 要化成 $\frac{13}{10}$ 再与分数相乘；除法要改乘倒数。
- 分母先算括号内和 $25$，再 $\times 20$，最后 $+3$，勿漏加 $3$。

## 第 2 题　（第3讲-大开眼界-2）

**答：$\dfrac{1}{2}$**

解析（自最内层向外）：

- $4 - \dfrac{6}{5} = \dfrac{14}{5}$
- $\dfrac{7}{14/5} = 7 \times \dfrac{5}{14} = \dfrac{5}{2}$
- $3 - \dfrac{5}{2} = \dfrac{1}{2}$
- $\dfrac{8}{1/2} = 8 \times 2 = 16$
- $2 + 16 = 18$；$\dfrac{9}{18} = \dfrac{1}{2}$
- $1 - \dfrac{1}{2} =$ **$\dfrac{1}{2}$**

### 易错提醒

- 繁分数每一层先算清，再代入上一层；$\dfrac{8}{1/2}$ 是 $8 \div \frac{1}{2}$，得 $16$ 不是 $\frac{8}{2}$。
- 最后要化到**最简分数**。

## 第 3 题　（第3讲-融会贯通-6）

**答：$1$**

解析：

- $1.65 = \dfrac{33}{20}$；$\dfrac{1}{4} + 0.8 = \dfrac{1}{4} + \dfrac{4}{5} = \dfrac{21}{20}$
- 第一项：$\dfrac{33}{20} \div \dfrac{21}{20} = \dfrac{33}{21} = \dfrac{11}{7}$
- 第二项：$\dfrac{1}{2} + \dfrac{1}{3} = \dfrac{5}{6}$；$\dfrac{5}{6} \times \dfrac{24}{35} = \dfrac{4}{7}$（先约 $5$ 与 $35$、$6$ 与 $24$）
- $\dfrac{11}{7} - \dfrac{4}{7} =$ **$1$**

### 易错提醒

- $1.65$ 写成 $\dfrac{33}{20}$，勿误为 $\dfrac{39}{20}$。
- 约分要前后对应：$\frac{5}{6} \times \frac{24}{35}$ 得 $\frac{4}{7}$，勿约成 $\frac{6}{7}$。
