## 坦克大战 · 积分与导弹

- **钱包键**：`gugeegoo_tank_lifetime_earned` / `_spent` / `_inventory`（与 snake 分离）
- **入账**：过关或结束/退出时按本局增量计入累计；可用 = 累计 − 消费
- **得分**：击毁敌人 +100；导弹击毁 +100+50；过关 +50
- **导弹**：商店 85 积分/枚，最多囤 8；对局 **K** 或 🚀 钮；2 秒冷却；3×3 爆砖，钢墙不动，可一发毁敌

配置：`items.js`、`shop.js`、`storage.js`；逻辑 `game-loop.js` + `map.explodeArea`。
