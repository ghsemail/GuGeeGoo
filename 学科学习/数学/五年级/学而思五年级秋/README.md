## 目录说明

- **`讲义/`** — 每讲知识点 Markdown；含 **`课程索引.md`**，总览各讲主题与录入进度。
- **`每日三题/`** — 按周归档的每日三题原题 PDF（如 `第1周.pdf`）；留存说明见该目录 **`README.md`**。
- **`练习/`** — 按讲分子目录 **`第N讲/`**：每讲含 **原题巩固**、**回顾训练** 及配套答案（MD/PDF）；题目源文件在 `第N讲/源文件/`。
- **`备忘/`** — 复习备忘（按讲命名的 MD/PDF，如 `第1讲-复习备忘.md`）。
