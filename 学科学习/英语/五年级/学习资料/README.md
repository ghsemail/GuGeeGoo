## 本目录放什么

| 类型 | 说明 | 命名建议 |
|------|------|----------|
| 教材 PDF | 外研社三起五上电子版或扫描（若入库） | `外研社三起五上-学生用书.pdf` 等 |
| 课文 | Get Ready / Start up / Speed up 原文（按单元） | `第N单元-课文.md` 或同名 PDF |
| 音频 / 视频 | 仅放 **链接说明** MD，大文件走网盘或 COS | `第N单元-音频链接.md` |
| 家长补充 | 阳光课堂截图、学校发的资料等 | 中文文件名，PDF 与配套 MD 同名（若做 MD 索引） |
| 单元测试卷（扫描） | 外研五上 WY 综合素养练等 | `WY五上测试卷.pdf` |

**不放这里：**

- 知识点整理 → `../讲义/`
- 练习、听写 → `../练习/`、`../词汇/`
- 插图扫描件（跨学科共用）→ 仓库根目录 `assets/images/`
