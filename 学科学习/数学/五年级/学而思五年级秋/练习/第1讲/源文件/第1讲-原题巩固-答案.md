## 第 1 题　（W1-Day1-1）

**a 列 · 化简后的比：1 : 2 · 比值：$\frac{1}{2}$**

**c 列 · 化简后的比：3 : 5 · 比值：$\frac{3}{5}$**

解析：

**a 列（0.15 : 0.3）**
- 0.15 : 0.3 = 15 : 30（同乘 100）
- 15 : 30 ÷15 → **1 : 2**
- 比值 = $1 \div 2 =$ **$\frac{1}{2}$**

**c 列（0.24 : $\frac{2}{5}$）**
- 0.24 = $\frac{24}{100} = \frac{6}{25}$
- $\frac{2}{5} = \frac{10}{25}$
- $\frac{6}{25} : \frac{10}{25}$ → **6 : 10** → **3 : 5**
- 比值 = $3 \div 5 =$ **$\frac{3}{5}$**

### 易错提醒

- 景源曾在 a、c 两列的小数、分数混合化简上失分；化简到前后项互质再写比值。
- 比值 = 前项 ÷ 后项，结果写最简分数。

## 第 2 题　（W1-Day1-3）

**答：4**

解析：

**第一步：设前两项**
- 前两项互为倒数，设为 x 与 $\frac{1}{x}$
- 比值 = $x \div \frac{1}{x} = x^2 = 4$ → x = 2（取正数）
- 前两项为 **2 : $\frac{1}{2}$**

**第二步：用内项积求第三项**
- 设比例式 $2 : \frac{1}{2} = m : n$，内项为 $\frac{1}{2}$ 与 m
- 内项积 = 4 → $\frac{1}{2} \times m = 4$ → **m = 8**

**第三步：用比值或外项积求第四项**
- 外项积 = 内项积 = 4 → $2 \times n = 4$ → **n = 2**
- 比例式：**$2 : \frac{1}{2} = 8 : 2$**

**第四步：外项之和**
- 外项 2 与 2 → 2 + 2 = **4**

验证：内项积 $\frac{1}{2} \times 8 = 4$ ✓；外项积 $2 \times 2 = 4$ ✓；前两项比值 $2 \div \frac{1}{2} = 4$ ✓

### 易错提醒

- 多条件要逐步用完；不要漏「内项积 = 外项积」。
- 「互为倒数」的两项乘积为 1。

## 第 3 题　（W1-Day2-4）

**答：C**

解析：

逐项验算内项积是否等于外项积：

- **A** $\frac{1}{6} : \frac{1}{4} = 12 : 8$ → $\frac{1}{6} \times 8 = \frac{4}{3}$，$\frac{1}{4} \times 12 = 3$ ✗
- **B** $8 : \frac{1}{4} = \frac{1}{6} : 12$ → $\frac{1}{4} \times \frac{1}{6} = \frac{1}{24}$，$8 \times 12 = 96$ ✗
- **C** $\frac{1}{6} : \frac{1}{4} = 8 : 12$ → $\frac{1}{6} \times 12 = 2$，$\frac{1}{4} \times 8 = 2$ ✓

### 易错提醒

- 景源曾选 B；分数在比例中要按**内项积 = 外项积**验算，不能凭感觉排顺序。

## 第 4 题　（W1-Day3-8）

**答：$\frac{124}{125}$**

解析：

- 后项 $123\frac{123}{124} = \frac{123 \times 124 + 123}{124} = \frac{123 \times 125}{124}$
- 比值 = $123 \div \frac{123 \times 125}{124}$
- $= 123 \times \frac{124}{123 \times 125}$
- $=$ **$\frac{124}{125}$**

### 易错提醒

- 带分数先化假分数；此题分子分母可约去 123，用巧算更快。

## 第 5 题　（W1-Day3-9）

**答：24 : 10 : 15**

解析：

设左侧阴影面积为 S。

- $S = \frac{\text{圆}}{8}$ → **圆 = 8S**
- $S = \text{长方形} \times \frac{3}{10}$ → **长方形 = $\frac{10S}{3}$**

右侧阴影面积 T 满足：

- $T = \text{大三角形} \times \frac{2}{15}$
- $T = \text{长方形} \times \frac{1}{5} = \frac{10S}{3} \times \frac{1}{5} =$ **$\frac{2S}{3}$**

由 $T = \text{大三角形} \times \frac{2}{15}$ 得 **大三角形 = $\frac{15T}{2} = \frac{15 \times (2S/3)}{2} = 5S$**

圆 : 长方形 : 大三角形 = $8S : \frac{10S}{3} : 5S$

同乘 $\frac{3}{S}$ → **24 : 10 : 15** ✓

### 易错提醒

- 景源曾写 **24 : 15 : 10**，计算对但**顺序**应按题目：圆、长方形、大三角形。
- 写答案前再读一遍题目中的三项顺序。

## 第 6 题　（W1-Day4-10）

**答：5 : 4**

解析：

- 长方形周长 = $2 \times (a + 2a) =$ **6a**
- 正五边形周长 = **5c**
- $6a = 1.5 \times 5c = 7.5c$
- $\frac{a}{c} = \frac{7.5}{6} = \frac{75}{60} =$ **$\frac{5}{4}$**
- **a : c = 5 : 4**

### 易错提醒

- 景源曾写 **9 : 5**，把 1.5 倍关系乘错边；应是「长方形周长 = 1.5 × 正五边形周长」→ $6a = 1.5 \times 5c$。
- 图意：竖边 a、横边 2a，别漏算一条横边。

## 第 7 题　（W1-Day4-11）

**答：8 : 15**

解析：

**化简 a : b**
- $\frac{3}{2} : 1.2 = \frac{3}{2} : \frac{6}{5} = \frac{15}{10} : \frac{12}{10} =$ **15 : 12** = **5 : 4**

**化简 b : c**
- $0.75 : \frac{1}{2} = \frac{3}{4} : \frac{1}{2} =$ **3 : 2**

**化连比（统一 b）**
- a : b = 5 : 4 → 乘 3 → **15 : 12**
- b : c = 3 : 2 → 乘 4 → **12 : 8**
- a : b : c = **15 : 12 : 8**

**题目求 c : a**
- c : a = 8 : 15

### 易错提醒

- 景源连比算对但曾写成 **a : c**；题目要 **c : a**，写答案前圈关键词。

## 第 8 题　（W1-Day4-12）

**答：16 : 8 : 9**

解析：

设甲的一半 = 乙的 3 倍 = 丙的 $\frac{2}{3}$ = k。

- $\frac{\text{甲}}{2} = k$ → **甲 = 2k**
- $3\text{乙} = k$ → **乙 = $\frac{k}{3}$**
- $\frac{2\text{丙}}{3} = k$ → **丙 = $\frac{3k}{2}$**

求 **甲的 $\frac{2}{3}$ : 乙的 2 倍 : 丙的一半**：

- 甲 $\times \frac{2}{3} = 2k \times \frac{2}{3} =$ **$\frac{4k}{3}$**
- 乙 $\times 2 = 2 \times \frac{k}{3} =$ **$\frac{2k}{3}$**
- 丙 $\times \frac{1}{2} = \frac{3k}{2} \times \frac{1}{2} =$ **$\frac{3k}{4}$**

比：$\frac{4k}{3} : \frac{2k}{3} : \frac{3k}{4}$

同乘 $\frac{12}{k}$ → **16 : 8 : 9**

### 易错提醒

- 等量关系先统一用 k 表示甲、乙、丙，再按题目做「甲的 $\frac{2}{3}$、乙的 2 倍、丙的一半」二次变换。
