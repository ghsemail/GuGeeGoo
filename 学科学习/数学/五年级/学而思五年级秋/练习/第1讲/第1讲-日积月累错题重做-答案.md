## 第 1 题　（第1讲-大开眼界-2）

**答：$24 : 20 : 45$**

解析：

**圆与正方形**（同一阴影面积）

- 设阴影面积为 1 份：$\frac{1}{6}S_{\text{圆}} = \frac{1}{5}S_{\text{正}} = 1$
- $S_{\text{圆}} = 6$，$S_{\text{正}} = 5$ → 圆 : 正 $= 6 : 5$

**三角形与正方形**（同一阴影面积）

- $\frac{1}{9}S_{\triangle} = \frac{1}{4}S_{\text{正}} = 1$
- $S_{\triangle} = 9$，$S_{\text{正}} = 4$ → 正 : 三角 $= 4 : 9$

**统一正方形份数**

- 正方形在两组里分别是 5 份、4 份，最小公倍数 $[5,4]=20$
- 圆 : 正 $= 6:5 = 24:20$；正 : 三角 $= 4:9 = 20:45$
- **圆 : 正 : 三角 $= 24 : 20 : 45$**

### 易错提醒

- 阴影是「桥梁」，先分别写出圆:正、正:三角，再统一中间量「正方形」。
- 写最终比时按题目顺序：圆、正方形、三角形。

## 第 2 题　（第1讲-大显身手-3）

**答：$49 : 48$**

解析：

- 甲 : 乙 $= 7 : 6$，乙 : 丙 $= 7 : 8$，统一乙：$[6,7]=42$
- 甲 : 乙 $= (7\times7):(6\times7)=49:42$
- 乙 : 丙 $= (7\times6):(8\times6)=42:48$
- 连比甲 : 乙 : 丙 $= 49 : 42 : 48$ → **甲 : 丙 $= 49 : 48$**

### 易错提醒

- 两个比里乙的份数不同（6 与 7），必须先统一乙再写甲:丙。
- 只问甲:丙时，中间量乙可以省略，但化连比过程要写出来。

## 第 3 题　（第1讲-融会贯通-7）

**答：$\dfrac{7}{4}$**

解析：

- $x$ 与 $y$ 互为倒数 → $xy = 1$
- 比例 $x : 8 = \frac{a}{y}$ 可写成 $x : 8 = a : y$（内项、外项对应）
- 内项积 = 外项积：$8a = xy = 1$ → $a = \dfrac{1}{8}$
- $14a = 14 \times \dfrac{1}{8} = \dfrac{7}{4}$

### 易错提醒

- $\dfrac{a}{y}$ 要看成比的后项，与 $x:8$ 对应为 $x:8=a:y$，再用内项积 = 外项积。
- 倒数条件 $xy=1$ 别漏。
