## 1. 每单元 4 类材料

> 来源：`学科学习/英语/五年级/练习/单元练习标准.md`

| 类型 | 命名（PDF，与源 MD 同名） | 说明 |
|------|---------------------------|------|
| 四天巩固 | `第N单元-四天巩固.pdf` + `第N单元-四天巩固-答案.pdf` | 4 页练习，答案合订不分页 |
| Memo | `第N单元-复习备忘.pdf` | 易错点备忘，课后看，**不是**测验 |
| 单元小测 | `第N单元-单元小测.pdf` + `第N单元-单元小测-答案.pdf` | 整单元短测（约 5～8 题） |
| 薄弱点回顾训练 | `第N单元-薄弱点回顾训练.pdf` + `-答案.pdf` | 针对档案薄弱点，可大字 |

### 源文件（`练习/第N单元/源文件/`）

- `第N单元-四天巩固-第1天.md` … `第4天.md`
- `第N单元-四天巩固-答案.md`
- `第N单元-单元小测.md` + `-答案.md`
- `第N单元-薄弱点回顾训练.md` + `-答案.md`
- `第N单元-练习索引.md`
- `第N单元-复习备忘.md`（Memo 源文件）

### 生成脚本（`练习/脚本/`）

- `generate-unit1-pdfs.mjs`、`generate-unit2-pdfs.mjs`
- `generate-memo-pdf.mjs`
- `pdf-theme.mjs`、`package.json`

### 不含在本标准内

- 首次基线作业（Unit 1 已存档为 `第1单元-基线测评-存档`）
- 独立的「记忆曲线」间隔测（若以后需要再增第五类）

## 2. 题量与字号

> 来源：`AGENTS.md` §6、§11 + `单元练习标准.md`

| 类型 | 题量 | 字号 | 备注 |
|------|------|------|------|
| 每日巩固练 | 7–10 题 | 17–20px | A4 每日一页，覆盖多个知识点 |
| 单元小测 | **5–8 题** ¹ | 20px+ | 聚焦 1–2 个薄弱点 |
| 复习备忘 | — | — | 单页卡片式 |
| 薄弱点回顾 | — | 可大字 | 针对档案薄弱点 |

**¹ 文档差异说明**：`单元练习标准.md` 写「约 5～8 题」，`AGENTS.md` §11 写「小测 5 题」；两条规则并存，暂不统一。

## 3. 出题依据

### 知识点来源

> 来源：`学科学习/英语/五年级/讲义/第N单元-<主题>.md`

每单元知识点文件包含：
- 课文原文与翻译
- 核心词块
- 重点短语
- 语法点
- 重点句型

### 薄弱点来源

> 来源：`学习档案/英语-水平档案.md`

按「当前关注」表格中的 WP-xxx 编号出题，覆盖当前薄弱点。

### 教材版本

牛津沪教版五年级上册

## 4. 家长判分 / 作答要求

> 来源：`老师配置/英语/MEMORY.md` 家长偏好

| 项目 | 要求 |
|------|------|
| 短语完整性 | 动词短语必须写完整（只写 Take 不写 Take off **算错**）；题目说明要明确要求写完整短语 |
| 祈使句大写 | 句首大写的祈使句动词算对（Try / try 都对） |
| 判分严格度 | 偏严格，培养写完整短语的习惯 |

## 5. 卷面格式

> 来源：`老师配置/英语/SOUL.md`

### 练习卷

| 项目 | 格式 |
|------|------|
| 标题 | 「Unit X 主题名 巩固练习」 |
| 内部序号 | **不带**（不写「练习 1」「练习 2」） |
| 副标题行 | 左「顾景源 · 五年级英语 · 牛津沪教版」，右「日期：________」 |
| 姓名栏 | **不要** |

### 答案卷

| 项目 | 格式 |
|------|------|
| 标注 | 「家长专用」 |
| 日期栏 | **无** |

### 学生可见内容禁止包含

- WP-xxx / MP-xxx 编码
- 知识点标签
- 内部来源标注（如「Day 3 Q9」）

### 输出格式

**只用 MD + PDF，绝不输出 HTML**

## 6. 流程

> 来源：`AGENTS.md` §7

```
草稿 → 学习路线图/练习索引 标「待家长确认」→ 生成 PDF → 批改后四档同步
```

1. **草稿**：创建 `源文件/第N单元-*.md` 及 `-答案.md`
2. **家长确认**：在学习路线图或练习索引标注「待家长确认」
3. **生成 PDF**：确认后执行单元脚本或 `npm run pdf`
4. **批改 → 四档同步**（见 AGENTS.md §5）
