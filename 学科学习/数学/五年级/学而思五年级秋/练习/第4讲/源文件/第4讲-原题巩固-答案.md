# 第 4 讲 分数应用题 原题巩固 答案

> 家长专用 · 批改时参考

## 第 1 题　（W4-Day1-3）

**答：48 人**

解析：
- 男生比女生多对应分率：$\frac{1}{4} - \frac{1}{6} = \frac{3}{12} - \frac{2}{12} = \frac{1}{12}$
- 全班人数：$4 \div \frac{1}{12} = 48$（人）

验证：女生 $48 \times \frac{1}{6} = 8$，男生 $48 \times \frac{1}{4} = 12$，$12 - 8 = 4$ ✓

### 易错提醒

- 分率差的基准都是「全班」；差量 4 人对应 $\frac{1}{12}$ 全班，勿把 4 直接当一份。
- 过程里 $\frac{1}{4}-\frac{1}{6}$ 宜通分写成 $\frac{1}{12}$（写 $\frac{2}{24}$ 也能算对，但约分要一致）。

## 第 2 题　（W4-Day2-3）

**答：四年级 176 人，五年级 154 人**

解析：
- 四年级是五年级的 $1 + \frac{1}{7} = \frac{8}{7}$
- 五年级：$330 \div \left(1 + \frac{8}{7}\right) = 330 \div \frac{15}{7} = 330 \times \frac{7}{15} = 154$（人）
- 四年级：$330 - 154 = 176$（人）（或 $154 \times \frac{8}{7} = 176$）

验证：$176 - 154 = 22$，$22 \div 154 = \frac{1}{7}$ ✓

### 易错提醒

- 「四年级比五年级多 $\frac{1}{7}$」→ 四年级 : 五年级 = $8 : 7$，总份数 15 份 = 330 人。
- 绿星表示过程对、仍按错题巩固时，要核对是否按家长标记记错。

## 第 3 题　（W4-Day3-2）

**答：五年级 390 人，六年级 650 人**

解析：
- 五年级：$300 \times \left(1 + \frac{3}{10}\right) = 300 \times \frac{13}{10} = 390$（人）
- 「五年级比六年级少 $\frac{2}{5}$」→ 五年级是六年级的 $1 - \frac{2}{5} = \frac{3}{5}$
- 六年级：$390 \div \frac{3}{5} = 390 \times \frac{5}{3} = 650$（人）

验证：$650 - 390 = 260$，$260 \div 650 = \frac{2}{5}$ ✓

### 易错提醒

- 「A 比 B 少 $\frac{2}{5}$」的基准是 **B（六年级）**，不是三年级或五年级。
- 两空都要填：先求五年级，再反推六年级。
