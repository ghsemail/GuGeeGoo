# 每日三题 · 留存说明

## 用途

留存学而思数学每周的「每日三题」原件与可选文字转录，便于日后查阅与对照讲次进度。

## 命名规则

按**周**存放，与学而思当周编号一致，例如：

| 文件 | 说明 |
|------|------|
| `第3周.pdf` | 家长提供的当周每日三题原件（扫描或导出 PDF） |
| `第3周.md` | 可选：题目文字转录，便于搜索与复制 |

若孩子作答或家长批改后需要纳入薄弱点追踪，错题另行录入 `学习档案/数学-错题本.md`，并走四档同步；本目录只负责**材料留存**，不替代错题本。
