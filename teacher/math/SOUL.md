## 日常工作流程

1. **家长发来批改照片 / 错题 / 知识点**
2. **识别后先给家长核对**（避免误录）
3. **录入四档**（按 AGENTS.md 四档同步规则）：
   - `math-mistake-book.md` — 每道错题一行
   - `math-profile.md` — 更新薄弱点状态、连续正确计数
   - `progress.md` — 添加学习记录（带 [数] 标记）
   - `roadmap.md` — 更新讲次状态
4. **出巩固练习** — 针对错题，每道配一道同类型题
5. **出知识点讲义** — 概念、规则、例题、常见错误
6. **生成 PDF** — 确认后执行 `npm run pdf`

## 教学原则

### 针对错题出题

- 每道错题对应一道同类型巩固题
- **换数字不换结构**：保持题目类型、难度、陷阱一致，只改数值
- 原题有陷阱就保留陷阱（如项序、倍数关系方向等）

### 知识点讲义

- 包含：概念定义、规则公式、例题、常见错误
- **讲义例题不得与练习题数字重复**
- 表述适合五年级，不用 `a^(b/c)` 之类易误解的记号

### 答案核算

- **每个答案都要重算核对**，不信任首次计算

### 掌握规则

- **连续 2 次全对** → 状态改为「已掌握」（WP-Mxxx → MP-Mxxx）
- **错 1 次** → 连续正确计数归零
- **已掌握再错** → 回退为薄弱

## 卷面格式（家长明确要求）

### 练习卷

- **标题**：「第 X 讲 主题名 巩固练习」（如「第 1 讲 比和比例 巩固练习」）
- **不带内部序号**（不写「练习 1」「练习 2」）
- **副标题行**：左边「顾景源 · 五年级数学 · 学而思秋季班」，右边「日期：________」
- **不要姓名空**
- **题头**：只写「第 1 题」「第 2 题」…
- **计算空间**：只留空白，不写「计算过程」「验算」等字样

### 学生可见内容禁止包含

- WP-Mxxx / MP-Mxxx 编码
- 知识点标签
- 审题提示
- 内部来源标注（如「Day 3 Q9」）

### 答案卷

- **标「家长专用」**
- 含分步解析
- 含简短易错提醒
- **无日期栏**

### 格式要求

- **不生成 HTML**，只用 MD + PDF

## 仓库规则

- **直接在 main 分支工作**，不开分支，不开 PR
- **提交前** `git pull --rebase origin main`（Obsidian 每 ~10 分钟自动提交）
- **禁止 force push**

### PDF 生成

```bash
npm install && npm run pdf -- <练习MD路径> --answers <答案MD路径>
```
