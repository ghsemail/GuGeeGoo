## 一、比的基本性质

**规则：** 比的前项和后项**同时乘或除以相同的数**（0 除外），比值不变。

**例子：** 6 : 9 = 2 : 3（前后项同除以 3）

---

## 二、化简含小数/分数/带分数的比

### 1. 小数比 → 整数比

**方法：** 同乘 10、100、1000…… 把小数变成整数，再化简。

**例子：** 0.18 : 0.36 → 同乘 100 → 18 : 36 → ÷18 → **1 : 2**

### 2. 分数比 → 整数比

**方法：** 同乘分母的公倍数，把分数变成整数。

**例子：** 1/4 : 3/8 → 同乘 8 → 2 : 3

### 3. 小数与分数混合

**方法：** 先统一成分数（或小数），再化简。

**例子：** 0.35 : 1/2 = 7/20 : 10/20 → 7 : 10

### 4. 带分数比

**方法：** 带分数先化成假分数。

**公式：** a^(b/c) = (a×c + b) / c

**例子：** 2³⁄₄ = (2×4+3)/4 = 11/4

---

## 三、化简 vs 求比值

| | 化简 | 求比值 |
|---|------|--------|
| **结果** | 一个比（如 3:5） | 一个数（如 3/5 或 0.6） |
| **计算** | 前后项同乘或同除 | 前项 ÷ 后项 |

**常见错误：** 比值的分子分母颠倒。记住：**比值 = 前项 ÷ 后项**。

---

## 四、比例的基本性质

**定义：** 表示两个比**相等**的式子叫做比例。

**基本性质：** 内项积 = 外项积

```
  a : b = c : d
  ↑外  ↑内 ↑内  ↑外
  
  → b × c = a × d
```

**例子：** 2 : 3 = 4 : 6 → 3×4 = 2×6 = 12 ✓

### 判断比例

用四个数组成比例时，**先算出乘积，找相等的两对**。

**例子：** 用 1/3、1/5、6、10 组成比例

- 1/3 × 6 = 2
- 1/5 × 10 = 2
- 所以 **1/3 : 1/5 = 10 : 6** ✓

---

## 五、化连比（统一中间量）

**问题：** 已知 a:b 和 b:c，求 a:b:c。

**方法：** 把两个比中的 b 统一成同一个数（找公倍数）。

**例子：** a:b = 2:3，b:c = 4:5

- b 的公倍数 = 12
- a:b = 2:3 → 乘 4 → 8:12
- b:c = 4:5 → 乘 3 → 12:15
- **a:b:c = 8:12:15**

---

## 六、注意项的顺序！

### ⚠️ 写答案前，用手指指着题目对照检查顺序

**常见错误：** 计算正确，但写反了顺序。

**例子：** 如果题目问「求 **c : a**」

- 你算出 a:b:c = 8:12:15
- **不要写** a:c = 8:15
- **要写** c:a = **15:8**

**习惯养成：** 写答案前，手指指着题目里的字母顺序，逐个填入。

---

## 七、由倍数/等量关系求比

### 倍数关系

**关键句：** 「A 是 B 的 1.5 倍」→ **A = 1.5 × B**

**常见错误：** 把倍数乘到了错误的一边。

**例子：** 正方形周长是正六边形周长的 1.2 倍，求 a:b

- 正方形周长 = 4a，正六边形周长 = 6b
- 4a = 1.2 × 6b = 7.2b
- a:b = 7.2:4 = **9:5**

### 等量关系

**关键句：** 「甲的 1/3 = 乙的 4 倍 = 丙的 1/2」

**方法：** 设等量为 k，用 k 表示甲、乙、丙。

**例子：**
- 甲的 1/3 = k → 甲 = 3k
- 乙的 4 倍 = k → 乙 = k/4
- 丙的 1/2 = k → 丙 = 2k
- 甲:乙:丙 = 3k : k/4 : 2k = **12:1:8**

## 八、自查清单

做完比和比例题目后，检查：

- [ ] 化简是否化到**最简**（前后项互质）？
- [ ] 比值是不是**前项 ÷ 后项**（没有颠倒）？
- [ ] 带分数有没有先化成**假分数**？
- [ ] 答案的**顺序**和题目要求一致吗？
- [ ] 倍数关系有没有写对**哪边乘倍数**？
