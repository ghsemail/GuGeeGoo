## 第 1 题

**a 列 · 化简后的比：1 : 2 · 比值：1/2**

**c 列 · 化简后的比：3 : 5 · 比值：3/5**

解析：

**a 列（0.15 : 0.3）**
- 0.15 : 0.3 = 15 : 30（同乘 100）
- 15 : 30 ÷15 → **1 : 2**
- 比值 = 1 ÷ 2 = **1/2**

**c 列（0.24 : 2/5）**
- 0.24 = 24/100 = 6/25
- 2/5 = 10/25
- 6/25 : 10/25 → **6 : 10** → **3 : 5**
- 比值 = 3 ÷ 5 = **3/5**

### 易错提醒

- 景源曾在 a、c 两列的小数、分数混合化简上失分；化简到前后项互质再写比值。
- 比值 = 前项 ÷ 后项，结果写最简分数。

## 第 2 题

**答：4**

解析：

**第一步：设前两项**
- 前两项互为倒数，设为 x 与 1/x
- 比值 = x ÷ (1/x) = x² = 4 → x = 2（取正数）
- 前两项为 **2 : 1/2**

**第二步：用内项积求第三项**
- 设比例式 2 : 1/2 = m : n，内项为 1/2 与 m
- 内项积 = 4 → 1/2 × m = 4 → **m = 8**

**第三步：用比值或外项积求第四项**
- 外项积 = 内项积 = 4 → 2 × n = 4 → **n = 2**
- 比例式：**2 : 1/2 = 8 : 2**

**第四步：外项之和**
- 外项 2 与 2 → 2 + 2 = **4**

验证：内项积 1/2 × 8 = 4 ✓；外项积 2 × 2 = 4 ✓；前两项比值 2 ÷ 1/2 = 4 ✓

### 易错提醒

- 多条件要逐步用完；不要漏「内项积 = 外项积」。
- 「互为倒数」的两项乘积为 1。

## 第 3 题

**答：C**

解析：

逐项验算内项积是否等于外项积：

- **A** 1/6 : 1/4 = 12 : 8 → 1/6 × 8 = 4/3，1/4 × 12 = 3 ✗
- **B** 8 : 1/4 = 1/6 : 12 → 1/4 × 1/6 = 1/24，8 × 12 = 96 ✗
- **C** 1/6 : 1/4 = 8 : 12 → 1/6 × 12 = 2，1/4 × 8 = 2 ✓

### 易错提醒

- 景源曾选 B；分数在比例中要按**内项积 = 外项积**验算，不能凭感觉排顺序。

## 第 4 题

**答：124/125**

解析：

- 后项 123 123/124 = (123×124 + 123)/124 = 123×125/124
- 比值 = 123 ÷ (123×125/124)
- = 123 × 124/(123×125)
- = **124/125**

### 易错提醒

- 带分数先化假分数；此题分子分母可约去 123，用巧算更快。

## 第 5 题

**答：24 : 10 : 15**

解析：

设左侧阴影面积为 S。

- S = 圆/8 → **圆 = 8S**
- S = 长方形×3/10 → **长方形 = 10S/3**

右侧阴影面积 T 满足：

- T = 大三角形×2/15
- T = 长方形×1/5 = (10S/3)×1/5 = **2S/3**

由 T = 大三角形×2/15 得 **大三角形 = 15T/2 = 15×(2S/3)/2 = 5S**

圆 : 长方形 : 大三角形 = 8S : 10S/3 : 5S

同乘 3/S → **24 : 10 : 15** ✓

### 易错提醒

- 景源曾写 **24 : 15 : 10**，计算对但**顺序**应按题目：圆、长方形、大三角形。
- 写答案前再读一遍题目中的三项顺序。

## 第 6 题

**答：5 : 4**

解析：

- 长方形周长 = 2×(a + 2a) = **6a**
- 正五边形周长 = **5c**
- 6a = 1.5 × 5c = 7.5c
- a/c = 7.5/6 = 75/60 = **5/4**
- **a : c = 5 : 4**

### 易错提醒

- 景源曾写 **9 : 5**，把 1.5 倍关系乘错边；应是「长方形周长 = 1.5 × 正五边形周长」→ 6a = 1.5×5c。
- 图意：竖边 a、横边 2a，别漏算一条横边。

## 第 7 题

**答：8 : 15**

解析：

**化简 a : b**
- 3/2 : 1.2 = 3/2 : 6/5 = 15/10 : 12/10 = **15 : 12** = **5 : 4**

**化简 b : c**
- 0.75 : 1/2 = 3/4 : 1/2 = **3 : 2**

**化连比（统一 b）**
- a : b = 5 : 4 → 乘 3 → **15 : 12**
- b : c = 3 : 2 → 乘 4 → **12 : 8**
- a : b : c = **15 : 12 : 8**

**题目求 c : a**
- c : a = 8 : 15

### 易错提醒

- 景源连比算对但曾写成 **a : c**；题目要 **c : a**，写答案前圈关键词。

## 第 8 题

**答：16 : 8 : 9**

解析：

设甲的一半 = 乙的 3 倍 = 丙的 2/3 = k。

- 甲/2 = k → **甲 = 2k**
- 3乙 = k → **乙 = k/3**
- 2丙/3 = k → **丙 = 3k/2**

求 **甲的 2/3 : 乙的 2 倍 : 丙的一半**：

- 甲×2/3 = 2k × 2/3 = **4k/3**
- 乙×2 = 2 × k/3 = **2k/3**
- 丙×1/2 = (3k/2)×1/2 = **3k/4**

比：4k/3 : 2k/3 : 3k/4

同乘 12/k → **16 : 8 : 9**

### 易错提醒

- 等量关系先统一用 k 表示甲、乙、丙，再按题目做「甲的 2/3、乙的 2 倍、丙的一半」二次变换。
