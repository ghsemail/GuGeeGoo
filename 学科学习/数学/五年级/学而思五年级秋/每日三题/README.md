# 每日三题 · 留存说明

## 用途

留存学而思数学每周的「每日三题」原件与可选文字转录，便于日后查阅与对照讲次进度。

## 命名规则

按**周**存放，与学而思当周编号一致。每周通常有**两份 PDF**：

| 文件 | 说明 |
|------|------|
| `第N周.pdf` | 家长提供的当周每日三题**原题**（扫描或导出 PDF） |
| `第N周-答案.pdf` | 学而思**官方答案**（含手写解题过程；家长 2026-10-05 提供） |
| `第N周.md` | 可选：题目文字转录，便于搜索与复制 |

若孩子作答或家长批改后需要纳入薄弱点追踪，错题另行录入 `学习档案/数学-错题本.md`，并走四档同步；本目录只负责**材料留存**，不替代错题本。
