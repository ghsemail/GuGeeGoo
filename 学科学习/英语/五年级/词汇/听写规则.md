## 零、开始前提：家长先说范围

听写开始前，必须由家长**明确说出**听写范围：**哪几个单元、哪种听写**。

- 家长**没有说清**范围时，老师**不开始听写**，也**不自行猜测**默认范围，只问家长要听写哪个范围。
- 家长**说清**范围后，须 **先备好词表** 再开始报读；**词表没准备好不开始听写**。
  - **单元单词听写**：词表 = 本次 Unit 单词表「按单元」+ 第一节范围内的待巩固词；**按该表** 逐词读。
  - **复习单词听写**：词表 = [听写单词本.md](./听写单词本.md)「**当前复习单词听写固定表**」（随机生成后 **存成固定表**）；**严格按表序号** 读，不每次重新随机。
- 词表就绪后，报总数、读第 1 个词（家长也可按第一节直接指定范围，以家长指令为准）。

**示例（家长怎么说）：**

- 「请听写第三单元的单词」→ **单元单词听写**（Unit 3）
- 「帮我听写一二单元复习听写」→ **复习单词听写**（若还指定了单元组合，以家长说法为准，再按第一节组词表）

## 一、听写范围

每次听写先选一种。家长说 **「单元单词听写 Unit N」** 或 **「复习单词听写」**；没说时我先问。

**单元单词听写**

- 本次单元（Unit N）的全部单词和短语（取单词表「按单元」）。
- 加上历史单元所有「不熟悉」「巩固中」的词（来源：[听写单词本.md](./听写单词本.md)「待巩固」表，或各单元听写文件里同状态的词）。
- 总数不限。

**复习单词听写**

- 历史单元所有「不熟悉」「巩固中」的词 **全部带上**。
- 再从已学过的历史单元里随机抽词补足，**总数控制在 20 个左右（18–22 个）**；不能太少（例如只听写 1 个词是不行的）。
- 抽词只从单词表里已学单元的词中抽，不听写单词表以外的词。
- 抽词优先：容易写错、容易和别的词混的词（例如 off 容易写成 of、over 容易写成 oven；of、oven 本身不听写），以及已掌握但隔了一段时间没听写的词；尽量覆盖各个已学单元。
- 若待巩固词本身已超过 22 个，本次 **只听写待巩固词**，不再抽补。
- 词表一旦生成，就存成固定表（见听写单词本「当前复习单词听写固定表」），之后复习单词听写严格按表中序号逐个读（读完一个词等家长说「下一个」再读下一个，不连续报词），不每次重新随机抽词；表里的词全部已掌握、有新的待巩固词或家长要求时才换表。

**历史单元**：已经学过 / 听写过的单元。

- 不听写：专有名词（人名、节日名等）和戏剧用语，除非家长另外指定。
- 家长也可以直接指定范围，例如「只听写 Unit 2」或「再加上 Unit 1 全部」，以家长指令为准。

## 二、出题顺序

1. 先确认词表已就绪（见零节、第一节），再报本次模式、总词数，以及其中多少个是待巩固词。
2. **待巩固** 表中备注 **「需中文提示」** 的词 **最先报读**（见第六节），即使上次拼写写对也要先听。单元单词听写：本单元词与复习词穿插、打乱顺序，但不打乱「需中文提示」优先。复习单词听写：其余词 **按固定表顺序**，不再临时打乱。
3. 每个词报读前带序号（第 1 个、第 2 个……），格式见第三节，方便回退和批改对号。

## 三、每个词怎么读

- **一律读英文**（单词或短语的英文形式），不主动读中文释义（孩子 **主动要中文意思** 时见第四节、第六节）。
- **每个词读之前先报序号**，格式：**「第 N 个，\<单词/短语\>」**（序号与英文之间用逗号）。
- 每个词读 **两遍**：报序号并读完第一遍后，紧接再读一遍英文，两遍之间 **不插入** 自动等待。
- **每读完当前词（含第二遍）即停**，不自动读下一个；报序号、读词、读完后 **不说任何多余的中文或英文**（不加提示、评价、解释）。家长或孩子说 **「下一个」**（或其它第四节指令）后再报下一词。
- 格式示例：「第 3 个，recycle。」紧接「recycle。」然后等待指令。

**孩子怎么写：**

- 每次听写都写：**英文单词/短语 + 中文意思**（与以前「读英文时」的要求相同）。
- 短语必须写完整，例如 take off、turn into、a few，不能只写 take。
- 句首大写的短语（如 Merry Christmas!）要照原样写出大写和标点。

**节奏：** 书写时间完全由家长/孩子控制；需要再听一遍时说「再读一遍」，准备好再发「下一个」。

## 四、对话指令

家长或孩子在对话里可以随时说：

开始类指令必须带范围，见零节。

| 指令 | 效果 |
|------|------|
| 单元单词听写 Unit N / 开始听写 Unit N | 按第一节确定范围，报总数后读第 1 个词（两遍英文），然后等待 |
| 复习单词听写 | 按第一节确定范围，报总数后读第 1 个词（两遍英文），然后等待 |
| 下一个 | 读下一个词（两遍英文），然后等待 |
| 没听清 / 再读一遍 | 把**当前**这个词再读两遍英文，然后等待 |
| 上一个 / 回到第 N 个 | 回到指定序号，读该词两遍英文，然后等待；之后仍须发「下一个」才继续 |
| 暂停 / 继续 | 暂停听写；继续时从停下的那个词再读两遍（或家长指定从哪一号开始） |
| 听写结束 | 停止出题，进入批改 |

- 回退、重读不算错，也不扣分，但会在记录里标一下「重读」，方便看出哪些词听起来容易混。
- 听写途中 **不主动** 提示拼写，也不告诉对错。
- **例外（覆盖上条「不给提示」）**：若顾景源 **主动要求** 说中文意思，可以告诉他；该词须记入错词本（见第五节、第六节），待巩固表 **备注** 标 **「需中文提示」**，作为 **优先复习词**（下次听写排在最前报读，见第二节）。

## 五、批改

1. 听写结束后，家长拍照发来孩子写的纸，或者直接打字发答案。
2. 我逐个对照单词表批改，**从严**：
   - 拼错一个字母就算错。
   - 短语少词算错（例如 take off 只写 take）。
   - 读英文时中文意思写错或没写，算「意思错」，单独记，不算拼写错。
   - 句首首字母大小写按项目已有规则：祈使句句首大写算对。
   - 听写中 **给了中文意思** 的词：按 **需巩固** 记入待巩固（拼写若全对也不按「已掌握」处理），备注 **「需中文提示」**。
3. 批改结果当场发给家长：总数、对几个、错了哪些、每个错词的正确写法；若有「需中文提示」词单独列出。
4. **错词重听写：** 错词 4 个及以下：不重听写。错词恰好 5 个：批改后自动只把本次错词再听写一遍，按本次错词顺序报读。错词 6 个及以上：批改后自动把整组词（本次听写的全部词，复习单词听写即固定表全部约 20 词）按原顺序重新听写一遍。重听写读法同正常听写（报序号、读两遍、等「下一个」）；重听写结果同样按第六节记入熟悉度。

## 六、记录与熟悉度

每次听写更新两处：

1. **[听写单词本.md](./听写单词本.md)**（全册总览）：「听写记录」加一行汇总；「待巩固」与尚未迁出的「单词状态」同步更新；**备注** 列写 **「需中文提示」**（及必要说明）。
2. **`练习/第N单元/第N单元-听写.md`**（本次单元，与 PDF 同级）：加一节听写明细；更新本单元单词状态；错词加记忆卡片；给了中文提示的词同样记入待巩固并标「需中文提示」。

**「需中文提示」优先复习：** 待巩固表中备注为「需中文提示」的词，**下一次听写最先报读**（第二节），连续 2 次 **无中文提示且全对** 后才按常规则升降熟悉度；期间拼写写对仍保留该备注，直至达标。

**状态规则**（和项目「连续 2 次全对为掌握」一致）：

| 情况 | 状态变为 |
|------|----------|
| 第一次听写就对 | 已掌握 |
| 写错 | 不熟悉（连对次数清零） |
| 不熟悉的词写对 1 次 | 巩固中（1/2） |
| 巩固中的词再写对 1 次 | 已掌握 |
| 已掌握的词复习时又错 | 退回不熟悉 |

## 七、不会的词怎么巩固

每个写错的词，当天在对应单元 [第N单元-听写.md](../练习/第N单元/第N单元-听写.md) 的「记忆卡片」里做一张卡片，按词的特点选一种记忆法：

| 记忆法 | 适合的词 | 例子 |
|--------|----------|------|
| 拆分法 | 合成词、能拆成熟词的词 | newspaper = news + paper；teaspoon = tea + spoon |
| 词族法 | 同一个词根变出来的词 | health → healthy → healthily；celebrate → celebration |
| 自然拼读 | 按发音能拼出来的词 | plate = pl + ate；flat = fl + at |
| 找相似词 | 拼写接近、容易混的词 | meat 和 meal；buy 和 by |
| 放进句子 | 短语和虚词 | turn into：Old bottles can turn into new things. |

**巩固步骤：**

1. 看卡片，读出记忆方法。
2. 盖住单词，照中文默写 3 遍。
3. 下一次听写自动带上这些词（见第一节）。
4. 连续 2 次写对后，卡片标「已掌握」，保留不删。
