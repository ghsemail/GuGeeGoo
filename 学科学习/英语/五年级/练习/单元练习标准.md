# 五年级英语 · 每单元练习标准

## 每单元 4 类材料（PDF 与配套 MD **同名**）

| 类型 | 命名示例（第 N 单元） |
|------|------------------------|
| 四天巩固 | `第N单元-四天巩固.pdf` ↔ 源：`第N单元-四天巩固-第1天.md` … `第4天.md`；答案：`第N单元-四天巩固-答案.pdf` ↔ `.md` |
| Memo | `第N单元-复习备忘.pdf` ↔ `.md` |
| 单元小测 | `第N单元-单元小测.pdf` ↔ `.md`；答案：`-答案` |
| 薄弱点回顾训练 | `第N单元-薄弱点回顾训练.pdf` ↔ `.md`；答案：`-答案` |

**听写（无 PDF）：** `第N单元/第N单元-听写.md` — 明细、本单元词状态、记忆卡片；全册汇总见 `词汇/听写单词本.md`。

**综合练习（与单元目录并列）：** `练习/综合练习/` — 听写错词 + 单元笔试（无听力）。命名：`综合练习-第N单元`、`综合练习-第1-2单元` 等；PDF 与 MD 同名。索引见 [`综合练习/README.md`](./综合练习/README.md)。与「四天巩固」「单元小测」区分：综合练习侧重听写错词复测 + 整单元笔试题型。

**四天巩固 PDF（Unit 3–6）：** `node generate-fourday-pdf.mjs N`

索引：`第N单元/源文件/第N单元-练习索引.md`

## 脚本

`练习/脚本/generate-unit1-pdfs.mjs`、`generate-unit2-pdfs.mjs`、`generate-memo-pdf.mjs`、`generate-comprehensive-pdfs.mjs`（`npm run comprehensive`）

## PDF 题间距（英语）

英语练习以客观题为主，题与题之间不留大空白，只留正常行距（约 0.8–1.2em）；仅**仿写 / 书面表达**留 2 行书写空；**改错、连词成句**留 1 行书写空（2026-10-05 家长要求）。生成时 `npm run pdf` 对 `学科学习/英语/` 下 worksheet 默认 `--english-compact`，数学练习仍用验算留白。
