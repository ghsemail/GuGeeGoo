# 新概念英语第一册 · 英语单词听写规则

> 顾景源 · 英语 · 对话模式听写  
> 词库：[单词表.md](./单词表.md)  
> 总览：[听写单词本.md](./听写单词本.md) · 课次明细：`练习/第N课/第N课-听写.md`  
> 精简：2026-10-22（按五年级听写规则精简稿适配到新概念第一册全册；含最严要求）

---

## 最严要求（每次听写都必须遵守）

1. 本次要听的每一个词，必须在听写开始前就备好完整词表（从官方单词表取出，可核对来源）。
2. **绝对禁止**现场联想、凭记忆编造、无中生有猜词。
3. 听写开始前，必须先把本次完整词表发给家长/顾景源看过并确认；**未确认不得开始报词**。
4. 报读过程中若对某个词是否在表上有任何不确定，立刻停下来查表，不猜、不跳过装作有。

---

## 零、开始前

- 家长先说清：哪几课（Lesson / 第 N 课）、哪种听写；没说清就不开始、不猜。
- 说清后先备好词表，表没备好不报词。
- 表就绪后报总数，再读第 1 个词（须先完成上方「最严要求」的确认）。

**示例：**

- 「请听写新概念第 3 课的单词」→ **课次单词听写**（第 3 课 / Lesson 3）
- 「帮我听写新概念复习听写」→ **复习单词听写**
- 「请听写 Lesson 1 和 Lesson 2」→ **课次单词听写**（第 1 课 + 第 2 课，按单词表「按课」合计）

## 一、两种听写

**课次单词听写**

- 本次课次（第 N 课，或家长指定的若干课）全部词 + 历史「不熟悉 / 巩固中」词；总数不限。词库为新概念第一册全册单词表。

**复习单词听写**

- 全部待巩固词 + 从已学课次抽词补到约 20 个（18–22）；待巩固已超过 22 则只听待巩固。
- 抽词只从单词表已学课次抽，不听表外词。
- 抽词优先：易错、易混词，以及已掌握但隔了一段时间没听的词；尽量覆盖各已学课次。
- 生成后存成固定表：只固定「听哪些词」，每次听写前重新打乱顺序再按序读；不每次重新抽词。
- 表内词全部已掌握、有新的待巩固词或家长要求时才换表。

**其他**

- 历史课次 = 已学过 / 听写过的课。
- 不听专有名词和戏剧用语（家长另指定除外）。
- 家长可临时指定或改范围，以家长指令为准。

## 二、出题顺序

1. 先报本次模式、总词数、其中待巩固几个。
2. 「需中文提示」的词最先报。
3. 其余词打乱后按本次固定顺序读；每个词前报序号。

## 三、每个词怎么读

- **一律读英文**，不主动念中文（孩子主动要中文意思除外，见第四节）。
- 格式：**「第 N 个，\<单词/短语\>。」** 紧接再念一遍英文，然后停下。
- 不加多余提示、评价、解释。家长或孩子说 **「下一个」** 后再报下一词。
- 孩子写：**英文 + 中文意思**；短语必须写完整（如 thank you，不能只写 thank）；句首大写短语照原样写。

## 四、对话指令

| 指令 | 效果 |
|------|------|
| 课次单词听写 第 N 课 / 课次单词听写 Lesson N / 开始听写第 N 课 | 按第一节确定范围，经最严要求确认后，报总数并读第 1 个词（两遍），然后等待 |
| 复习单词听写 / 新概念复习听写 | 同上 |
| 下一个 | 读下一个词（两遍），然后等待 |
| 没听清 / 再读一遍 | 把当前词再读两遍，然后等待 |
| 上一个 / 回到第 N 个 | 回到指定序号，读该词两遍，然后等待 |
| 暂停 / 继续 | 暂停；继续时从停下的词再读两遍（或家长指定从哪一号） |
| 听写结束 | 停止出题，进入批改 |

- 回退、重读不算错，记录里可标「重读」。
- 途中不主动提示拼写，也不告诉对错。
- **例外：** 顾景源主动要求说中文意思时可以告诉他；该词记入待巩固，备注 **「需中文提示」**，下次最先报。

## 五、批改

1. 听写结束后，家长拍照或打字发答案。
2. 对照单词表从严批改：
   - 拼错一个字母就算错。
   - 短语少词算错。
   - 中文意思写错或没写，算「意思错」，单独记，不算拼写错。
   - 祈使句句首大写算对。
   - 给过中文意思的词记入待巩固（拼写全对也不按「已掌握」），备注「需中文提示」。
3. 当场反馈：总数、对几个、错了哪些、正确写法；「需中文提示」词单独列出。
4. **错词重听写：** ≤4 个不重听；正好 5 个只重听错词（重新打乱）；≥6 个整组重听（重新打乱）。

## 六、记录与熟悉度

每次更新：

1. [听写单词本.md](./听写单词本.md)：听写记录一行 + 待巩固同步。练习目录尚无课文件夹时，明细与记忆卡片也先写在本文件内。
2. `练习/第N课/第N课-听写.md`（练习目录按课建好后）：明细、本课状态、记忆卡片。

**熟悉度：**

| 情况 | 状态变为 |
|------|----------|
| 第一次听写就对 | 已掌握 |
| 写错 | 不熟悉（连对清零） |
| 不熟悉的词写对 1 次 | 巩固中（1/2） |
| 巩固中的词再写对 1 次 | 已掌握 |
| 已掌握的词复习时又错 | 退回不熟悉 |

「需中文提示」须连续 2 次无中文提示且全对后，才按上表升降；期间拼对仍保留该备注。

## 七、不会的词怎么巩固

每个错词当天做一张记忆卡片，选用合适记忆法（拆分 / 词族 / 自然拼读 / 找相似词 / 放进句子）。练习目录尚无 `练习/第N课/` 时写在听写单词本内；有课文件夹后迁至对应课听写文件。

**步骤：** 看卡片 → 照中文默写 3 遍 → 下次听写自动带上 → 连续 2 次写对后标「已掌握」（卡片保留）。
