# 五年级上 · 英语单词听写规则

> 顾景源 · 英语 · 对话模式听写  
> 词库：[外研社三起五上-单词表.md](./外研社三起五上-单词表.md)  
> 记录：[听写单词本.md](./听写单词本.md)  
> 制定：2026-09-26（按家长提出的四条要求）  
> 修订：2026-09-26 — 全部读英文；词与词之间不自动停顿，等「下一个」指令

---

## 一、听写范围

每次听写 = **本次单元的全部单词** + **前面各单元还不熟悉的单词**。

- 本次单元的词：取单词表「按单元」里该单元的全部单词和短语。
- 前面单元的词：取 [听写单词本.md](./听写单词本.md) 「单词状态」里前面单元状态为「不熟悉」或「巩固中」的词。
- 不听写：专有名词（人名、节日名等）和戏剧用语，除非家长另外指定。
- 家长也可以直接指定范围，例如「只听写 Unit 2」或「再加上 Unit 1 全部」，以家长指令为准。

**第一次开始时：** Unit 1 还没听写过，前面没有「不熟悉」的记录。建议先听写 Unit 1，再听写 Unit 2，之后每次按上面的规则进行。

## 二、出题顺序

1. 先报本次听写的总词数，以及其中多少个是前面单元的复习词。
2. 本单元的词打乱顺序，复习词穿插在里面，不单独放在最后。
3. 每个词都带序号（第 1 个、第 2 个……），方便回退和批改对号。

## 三、每个词怎么读

- **一律读英文**（单词或短语的英文形式），不读中文释义。
- 每个词读 **两遍**，两遍紧挨着读完，中间 **不插入** 自动等待。
- 读完当前词后 **停住**，不自动读下一个；家长或孩子说 **「下一个」**（或其它第四节指令）后再报下一词。
- 格式示例：「第 3 个。recycle。recycle。」然后等待指令。

**孩子怎么写：**

- 每次听写都写：**英文单词/短语 + 中文意思**（与以前「读英文时」的要求相同）。
- 短语必须写完整，例如 take off、turn into、a few，不能只写 take。
- 句首大写的短语（如 Merry Christmas!）要照原样写出大写和标点。

**节奏：** 书写时间完全由家长/孩子控制；需要再听一遍时说「再读一遍」，准备好再发「下一个」。

## 四、对话指令

家长或孩子在对话里可以随时说：

| 指令 | 效果 |
|------|------|
| 开始听写 Unit N | 按第一节确定范围，报总数后读第 1 个词（两遍英文），然后等待 |
| 下一个 | 读下一个词（两遍英文），然后等待 |
| 没听清 / 再读一遍 | 把**当前**这个词再读两遍英文，然后等待 |
| 上一个 / 回到第 N 个 | 回到指定序号，读该词两遍英文，然后等待；之后仍须发「下一个」才继续 |
| 暂停 / 继续 | 暂停听写；继续时从停下的那个词再读两遍（或家长指定从哪一号开始） |
| 听写结束 | 停止出题，进入批改 |

- 回退、重读不算错，也不扣分，但会在记录里标一下「重读」，方便看出哪些词听起来容易混。
- 听写途中不提示拼写，也不告诉对错。

## 五、批改

1. 听写结束后，家长拍照发来孩子写的纸，或者直接打字发答案。
2. 我逐个对照单词表批改，**从严**：
   - 拼错一个字母就算错。
   - 短语少词算错（例如 take off 只写 take）。
   - 读英文时中文意思写错或没写，算「意思错」，单独记，不算拼写错。
   - 句首首字母大小写按项目已有规则：祈使句句首大写算对。
3. 批改结果当场发给家长：总数、对几个、错了哪些、每个错词的正确写法。

## 六、记录与熟悉度

每次听写都记进 [听写单词本.md](./听写单词本.md)：

- 「听写记录」加一次的明细（日期、范围、得分、错词）。
- 「单词状态」更新每个词的状态。

**状态规则**（和项目「连续 2 次全对为掌握」一致）：

| 情况 | 状态变为 |
|------|----------|
| 第一次听写就对 | 已掌握 |
| 写错 | 不熟悉（连对次数清零） |
| 不熟悉的词写对 1 次 | 巩固中（1/2） |
| 巩固中的词再写对 1 次 | 已掌握 |
| 已掌握的词复习时又错 | 退回不熟悉 |

## 七、不会的词怎么巩固

每个写错的词，当天在 [听写单词本.md](./听写单词本.md) 的「记忆卡片」里做一张卡片，按词的特点选一种记忆法：

| 记忆法 | 适合的词 | 例子 |
|--------|----------|------|
| 拆分法 | 合成词、能拆成熟词的词 | newspaper = news + paper；teaspoon = tea + spoon |
| 词族法 | 同一个词根变出来的词 | health → healthy → healthily；celebrate → celebration |
| 自然拼读 | 按发音能拼出来的词 | plate = pl + ate；flat = fl + at |
| 找相似词 | 拼写接近、容易混的词 | meat 和 meal；buy 和 by |
| 放进句子 | 短语和虚词 | turn into：Old bottles can turn into new things. |

**巩固步骤：**

1. 看卡片，读出记忆方法。
2. 盖住单词，照中文默写 3 遍。
3. 下一次听写自动带上这些词（见第一节）。
4. 连续 2 次写对后，卡片标「已掌握」，保留不删。
