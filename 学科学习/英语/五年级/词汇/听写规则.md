## 1. 需求确认

先和用户明确听写范围，例如：新概念听写第 1–3 课，或校内听写第 1–3 单元。范围未说清不备表、不开听。

## 2. 词表准备

按范围从官方单词表取词：

- **单个**单元 / 课：该范围**全量**
- **多个**单元 / 课：随机约 **20** 个（可含该范围内待巩固词）

禁止凭记忆编造表外词。

## 3. 词表确认

把本次完整词表发给用户确认。**未确认不得开始报词。**

## 4. 听写播报

- 格式：**「第 N 个，<英文>。」** 紧接再念一遍英文，然后**立刻停下**。
- **不读拼写**；**不主动读中文意思**（用户明确要求时才读）。
- **禁止任何多余话**：不评论、不催促、不解释、不说「好了」「说下一个再继续」等。报完即静音等待。

## 5. 播报指令

收到指令后**立刻执行**，中间不加任何话：

| 指令 | 动作 |
|------|------|
| **开始** | 报第 1 个词（两遍），停下 |
| **下一个** | **立刻**报下一个词（两遍），停下。听到「下一个」必须马上报，不得无反应、不得先说话 |
| **再读一遍** | 把**当前**词再读两遍，停下 |
| **上一个** | 回到上一词，读两遍，停下 |
| **回到第 N 个** | 跳到第 N 个，读两遍，停下 |
| **暂停** | 停止报词，等待 |
| **继续** | 从暂停处的词再读两遍（或用户指定序号），停下 |
| **听写结束** | 停止出题，进入批改 |
