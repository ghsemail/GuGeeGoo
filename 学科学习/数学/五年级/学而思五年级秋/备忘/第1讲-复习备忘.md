## 一、比的基本性质

**规则：** 比的前项和后项**同时乘或除以相同的数**（0 除外），比值不变。

**例子：** 6 : 9 = 2 : 3（前后项同除以 3）

---

## 二、化简含小数/分数/带分数的比

### 1. 小数比 → 整数比

**方法：** 同乘 10、100、1000…… 把小数变成整数，再化简。

**例子：** 0.24 : 0.32 → 同乘 100 → 24 : 32 → ÷8 → **3 : 4**

### 2. 分数比 → 整数比

**方法：** 同乘分母的公倍数，把分数变成整数。

**例子：** 2/5 : 3/10 → 同乘 10 → 4 : 3

### 3. 小数与分数混合

**方法：** 先统一成分数（或小数），再化简。

**例子：** 0.4 : 2/3 = 2/5 : 2/3 → 同乘 15 → 6 : 10 → **3 : 5**

### 4. 带分数比

**方法：** 带分数先化成假分数。

**口诀：** 整数×分母＋分子 作分子，分母不变。

**例子：** 3²⁄₅ = (3×5+2)/5 = 17/5

---

## 三、化简 vs 求比值

| | 化简 | 求比值 |
|---|------|--------|
| **结果** | 一个比（如 3:5） | 一个数（如 3/5 或 0.6） |
| **计算** | 前后项同乘或同除 | 前项 ÷ 后项 |

**常见错误：** 比值的分子分母颠倒。记住：**比值 = 前项 ÷ 后项**。

---

## 四、比例的基本性质

**定义：** 表示两个比**相等**的式子叫做比例。

**基本性质：** 内项积 = 外项积

```
  a : b = c : d
  ↑外  ↑内 ↑内  ↑外
  
  → b × c = a × d
```

**例子：** 2 : 3 = 4 : 6 → 3×4 = 2×6 = 12 ✓

### 判断比例

用四个数组成比例时，**先算出乘积，找相等的两对**。

**例子：** 用 2、3、8、12 组成比例

- 2 × 12 = 24
- 3 × 8 = 24
- 所以 **2 : 3 = 8 : 12** ✓

---

## 五、化连比（统一中间量）

**问题：** 已知 a:b 和 b:c，求 a:b:c。

**方法：** 把两个比中的 b 统一成同一个数（找公倍数）。

**例子：** a:b = 2:3，b:c = 4:5

- b 的公倍数 = 12
- a:b = 2:3 → 乘 4 → 8:12
- b:c = 4:5 → 乘 3 → 12:15
- **a:b:c = 8:12:15**

---

## 六、注意项的顺序！

### ⚠️ 写答案前，用手指指着题目对照检查顺序

**常见错误：** 计算正确，但写反了顺序。

**例子：** 如果题目问「求 **c : a**」

- 你算出 a:b:c = 8:12:15
- **不要写** a:c = 8:15
- **要写** c:a = **15:8**

**习惯养成：** 写答案前，手指指着题目里的字母顺序，逐个填入。

---

## 七、由倍数/等量关系求比

### 倍数关系

**关键句：** 「A 是 B 的 1.5 倍」→ **A = 1.5 × B**

**常见错误：** 把倍数乘到了错误的一边。

**例子：** 甲数是乙数的 1.5 倍，求甲:乙

- 甲 = 1.5 × 乙
- 甲:乙 = 1.5:1 = **3:2**

### 等量关系

**关键句：** 「甲的 1/2 = 乙的 3 倍 = 丙的 1/4」

**方法：** 设等量为 k，用 k 表示甲、乙、丙。

**例子：**
- 甲的 1/2 = k → 甲 = 2k
- 乙的 3 倍 = k → 乙 = k/3
- 丙的 1/4 = k → 丙 = 4k
- 甲:乙:丙 = 2k : k/3 : 4k = **6:1:12**

## 八、自查清单

做完比和比例题目后，检查：

- [ ] 化简是否化到**最简**（前后项互质）？
- [ ] 比值是不是**前项 ÷ 后项**（没有颠倒）？
- [ ] 带分数有没有先化成**假分数**？
- [ ] 答案的**顺序**和题目要求一致吗？
- [ ] 倍数关系有没有写对**哪边乘倍数**？
