# 第 1 讲 比和比例 巩固练习 答案

> 家长专用 · 批改时参考

---

## 第 1 题

**化简后的比：1 : 2**

**比值：1/2**

解析：
- 0.18 : 0.36
- 同乘 100 → 18 : 36
- ÷18 → **1 : 2**
- 比值 = 1 ÷ 2 = **1/2**

### 易错提醒

- 化简要化到最简（前后项互质）
- 比值 = 前项 ÷ 后项，不要颠倒

---

## 第 2 题

**化简后的比：7 : 10**

**比值：7/10**

解析：
- 0.35 : 1/2
- 0.35 = 35/100 = 7/20
- 1/2 = 10/20
- 7/20 : 10/20 → 去分母 → 7 : 10
- 比值 = 7 ÷ 10 = **7/10**

### 易错提醒

- 小数与分数混合时，先统一成分数（通分母）或小数
- 分数比去分母后再化简

## 第 3 题

**答：6**

解析：

**第一步：求前两项**
- 前两项互为倒数，设为 x 和 1/x
- 比值 = x ÷ (1/x) = x² = 9
- 所以 x = 3
- 前两项是 **3 : 1/3**

**第二步：求另外两项**
- 设比例式为 3 : 1/3 = □ : △
- 在 a:b = c:d 中，**b 和 c 是内项，a 和 d 是外项**
- 所以：内项是 1/3 和 □，外项是 3 和 △
- 内项积 = 9 → 1/3 × □ = 9 → □ = 27
- 比值 = 9 → 27 ÷ △ = 9 → △ = 3
- 比例式：3 : 1/3 = 27 : 3

**第三步：求外项之和**
- 外项是 3 和 3
- 外项之和 = 3 + 3 = **6**

验证：内项积 = 1/3 × 27 = 9 ✓，外项积 = 3 × 3 = 9 ✓

### 易错提醒

- 「互为倒数」意味着乘积为 1（如 3 和 1/3）
- 比值 = 前项 ÷ 后项
- 分步解，每步解一个未知数

## 第 4 题

**答：能；1/3 : 1/5 = 10 : 6**（或 1/5 : 1/3 = 6 : 10 等）

解析：
- 检验：1/3 × 6 = 2，1/5 × 10 = 2
- 内项积 = 外项积 = 2 ✓
- 所以 **1/3 : 1/5 = 10 : 6** 成立

其他正确写法：
- 1/5 : 1/3 = 6 : 10
- 6 : 10 = 1/3 : 1/5
- 10 : 6 = 1/5 : 1/3

### 易错提醒

- 比例的基本性质：**内项积 = 外项积**
- 组成比例后要验算

## 第 5 题

**比值：46/47**

解析：
- 45⁴⁵⁄₄₆ = (45×46 + 45)/46 = 45×(46+1)/46 = 45×47/46
- 比值 = 45 ÷ (45×47/46)
- = 45 × 46/(45×47)
- = **46/47**

### 易错提醒

- 带分数先化假分数：整数×分母＋分子 作分子，分母不变
- 此题可用巧算：45 ÷ (45×47/46) = 46/47

## 第 6 题

**答：20 : 15 : 3**

解析：

**第一步：写出各比**
- 圆占长方形 1/5 → 圆 : 长方形 = 1 : 5
- 长方形占三角形 3/4 → 长方形 : 三角形 = 3 : 4

**第二步：化连比（统一长方形）**
- 长方形的公倍数 = 15
- 圆 : 长方形 = 1 : 5 → 乘 3 → 3 : 15
- 长方形 : 三角形 = 3 : 4 → 乘 5 → 15 : 20
- 圆 : 长方形 : 三角形 = 3 : 15 : 20

**第三步：按题目顺序写答案**
- 题目问 **三角形 : 长方形 : 圆**
- 答案：**20 : 15 : 3**

### 易错提醒

- ⚠️ **写答案前对照题目检查顺序！**
- 题目问的是「三角形 : 长方形 : 圆」，不是「圆 : 长方形 : 三角形」

## 第 7 题

**答：9 : 5**

解析：
- 正方形周长 = 4a
- 正六边形周长 = 6b
- 「正方形周长是正六边形周长的 1.2 倍」
- → 4a = 1.2 × 6b = 7.2b
- → a : b = 7.2 : 4 = 72 : 40 = **9 : 5**

### 易错提醒

- **「A 是 B 的 1.2 倍」→ A = 1.2 × B**
- 不要把 1.2 乘到错误的一边

## 第 8 题

**答：3 : 5**

解析：

**第一步：化简各比**
- a : b = 5/3 : 1.5 = 5/3 : 3/2
- 同乘 6 → 10 : 9
- a : b = **10 : 9**

- b : c = 0.9 : 3/5 = 0.9 : 0.6 = 9 : 6 = 3 : 2
- b : c = **3 : 2**

**第二步：化连比（统一 b）**
- b 的公倍数 = 9
- a : b = 10 : 9
- b : c = 3 : 2 → 乘 3 → 9 : 6
- a : b : c = **10 : 9 : 6**

**第三步：按题目顺序写答案**
- 题目问 **c : a**
- 答案：6 : 10 = **3 : 5**

### 易错提醒

- ⚠️ **写答案前对照题目检查顺序！**
- 题目问的是「c : a」，不是「a : c」

## 第 9 题

**答：6 : 3 : 2**

解析：

**第一步：设等量为 k，求甲、乙、丙**
- 甲的 1/3 = 乙的 4 倍 = 丙的 1/2 = k
- 甲 = 3k
- 乙 = k/4
- 丙 = 2k
- 甲 : 乙 : 丙 = 3k : k/4 : 2k = **12 : 1 : 8**

**第二步：求变换后的比**
- 甲的一半 = 3k ÷ 2 = 3k/2
- 乙的 3 倍 = k/4 × 3 = 3k/4
- 丙的 1/4 = 2k ÷ 4 = k/2

**第三步：化简**
- 3k/2 : 3k/4 : k/2
- 同乘 4/k → 6 : 3 : 2
- 答案：**6 : 3 : 2**

### 易错提醒

- 分步解：先求原比，再按题目要求变换
- 等量关系建立后，用同一个字母 k 表示
