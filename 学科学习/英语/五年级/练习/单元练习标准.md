# 五年级英语 · 每单元练习标准

## 每单元 4 类材料（PDF 与配套 MD **同名**）

| 类型 | 命名示例（第 N 单元） |
|------|------------------------|
| 四天巩固 | `第N单元-四天巩固.pdf` ↔ 源：`第N单元-四天巩固-第1天.md` … `第4天.md`；答案：`第N单元-四天巩固-答案.pdf` ↔ `.md` |
| Memo | `第N单元-复习备忘.pdf` ↔ `.md` |
| 单元小测 | `第N单元-单元小测.pdf` ↔ `.md`；答案：`-答案` |
| 薄弱点回顾训练 | `第N单元-薄弱点回顾训练.pdf` ↔ `.md`；答案：`-答案` |

索引：`第N单元/源文件/第N单元-练习索引.md`

## 脚本

`练习/脚本/generate-unit1-pdfs.mjs`、`generate-unit2-pdfs.mjs`、`generate-memo-pdf.mjs`

## 不含

- 基线测评存档（Unit 1：`第1单元-基线测评-存档`）
- 独立记忆曲线间隔测（未建）
