# 第 1 讲 比和比例 巩固练习 答案

> 家长专用 · 批改时参考

---

## 第 1 题

**（1）化简后：2:5，比值：2/5**

解析：
- 0.18 : 0.45
- 同乘 100 → 18 : 45
- ÷9 → **2 : 5**
- 比值 = 2 ÷ 5 = **2/5**

**（2）化简后：2:5，比值：2/5**

解析：
- 0.32 : 4/5
- 0.32 = 32/100 = 8/25，4/5 = 20/25
- 8/25 : 20/25 → 8 : 20
- ÷4 → **2 : 5**
- 比值 = 2 ÷ 5 = **2/5**

**（3）化简后：45:46，比值：45/46**

解析：
- 18²⁄₅ = (18×5+2)/5 = 92/5
- 18 : 92/5
- 同乘 5 → 90 : 92
- ÷2 → **45 : 46**
- 45 和 46 互质，已是最简整数比
- 比值 = 45 ÷ 46 = **45/46**

---

### ⚠️ 易错提醒（第 1 题）

- **带分数先化假分数**：18²⁄₅ = (18×5+2)/5 = 92/5
- **小数与分数混合时**：统一成分数或小数后再化简
- **比值 = 前项 ÷ 后项**，不要颠倒

## 第 2 题

**丙 : 乙 : 甲 = 9 : 12 : 16**

解析：

**第一步：化简各比**
- 甲 : 乙 = 2/3 : 0.5 = 2/3 : 1/2
- 同乘 6 → 4 : 3
- 所以 甲 : 乙 = 4 : 3

- 乙 : 丙 = 0.8 : 3/5 = 0.8 : 0.6 = 4 : 3
- 所以 乙 : 丙 = 4 : 3

**第二步：化连比（统一「乙」）**
- 甲 : 乙 = 4 : 3 → 乘 4 → 16 : 12
- 乙 : 丙 = 4 : 3 → 乘 3 → 12 : 9
- 所以 甲 : 乙 : 丙 = 16 : 12 : 9

**第三步：按题目顺序写答案**
- 题目问的是 **丙 : 乙 : 甲**（注意顺序！）
- 丙 : 乙 : 甲 = 9 : 12 : 16
- ÷ 公因数检验：9、12、16 的公因数只有 1
- **答案：9 : 12 : 16**

---

### ⚠️ 易错提醒（第 2 题）

- **计算正确但顺序写反**是常见错误
- **习惯养成**：连比算出后，**用手指指着题目要求的顺序**，逐项对照填入答案
- 本题要求 **丙:乙:甲**，不是 甲:乙:丙！

## 第 3 题

**b : c = 5 : 4**

解析：

**第一步：列出周长关系**
- 长方形周长 = 2(a + b) = 2(2b + b) = 6b（因为 a = 2b）
- 正六边形周长 = 6c

**第二步：根据倍数关系建等式**
- 长方形周长 = 1.25 × 正六边形周长
- 6b = 1.25 × 6c
- 6b = 7.5c

**第三步：化比**
- b : c = 7.5 : 6
- 同乘 2 → 15 : 12
- ÷3 → **5 : 4**

---

### ⚠️ 易错提醒（第 3 题）

- **把倍数乘到了错误的一边**是常见错误
- **正确理解**：「A 是 B 的 1.25 倍」→ A = 1.25 × B
- 本题：长方形周长(6b) = 1.25 × 正六边形周长(6c)
