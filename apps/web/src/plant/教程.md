# 养电子植物 · 编程小教程

> 给五年级的景源：这份说明和仓库里的代码是一一对应的，你可以一边玩一边学。

---

## 1. 这个游戏在做什么？

你在网页里**选一种苔藓 → 种下 → 浇水 / 晒太阳 / 施肥**，三条状态条会随时间慢慢下降。照顾得当，苔藓会从 **孢子** 一直长到 **成熟**；照顾太久不对，它会变黄、停长，最后枯萎。

---

## 2. 文件地图（每个文件干什么）

| 文件 | 作用（小朋友版） |
|------|------------------|
| `apps/web/plant/index.html` | 网页骨架：标题、卡片、花盆、按钮、图鉴 |
| `plant.css` | 颜色、布局、动画（水滴、阳光闪一下） |
| `main.js` | 把按钮和定时器连起来，刷新画面 |
| `species.js` | 七种苔藓的名字、习性、**理想水分/阳光/养分** |
| `constants.js` | **可调快慢**的数字（排水、成长、存档间隔） |
| `growth.js` | 真正的「游戏规则」：每秒怎么变、健不健康 |
| `storage.js` | 存盘 / 读盘（`localStorage`） |
| `plant3d.js` | 用 Three.js 画 3D 花盆和苔藓（能转、能缩放） |
| `draw.js` | 2D 备用画法（WebGL 不可用时） |
| `references-3d.md` | 3D 造型参考的真实资料链接 |
| `facts.js` | 轮流显示的小知识 |

## 3. 游戏心跳（定时器）

在 `main.js` 里，`startLoops()` 做了三件事：

```javascript
// 每隔 TICK_INTERVAL_MS（默认 1 秒）算一次状态
setInterval(gameTick, TICK_INTERVAL_MS);

// 每隔 AUTO_SAVE_MS 自动存档
setInterval(persistSave, AUTO_SAVE_MS);

// 每隔 12 秒换一条小知识
setInterval(rotateFact, 12000);
```

`gameTick()` 会调用 `tickPlant()`（在 `growth.js`），根据**过了多少秒**更新水分、阳光、养分和成长进度。

---

## 4. 三条状态条怎么变？

在 `constants.js` 里：

```javascript
export const DRAIN_PER_SEC = {
  water: 0.072,    // 每秒水分少多少
  light: 0.048,
  nutrient: 0.026,
};
```

点按钮时，`applyCareAction()` 会加上 `ACTION_BOOST` 里的数，并有一个短冷却，防止连点刷分。

---

## 5. 心情与健康（能不能长？）

`assessCare()` 会拿当前三条数值，和 `species.js` 里这种苔藓的 **ideals**（合适范围）比：

- 太干、太晒、肥太多 → `ok: false`，**不长进度**，`stressSec` 增加  
- 连续不当照顾超过 `WITHER_AFTER_NEGLECT_SEC`（约 200 秒）→ **枯萎**  
- 都在合适范围 → 每秒加 `GROWTH_PER_SEC_HEALTHY`，大约 **12 分钟** 养满

提示语例子在 `buildHint()`：地钱怕暴晒、叉钱苔要多水等。

---

## 6. 成长阶段

总进度 `growth` 是 0～100。`stageIndexFromGrowth()` 分成五段：

| 进度 | 阶段名 |
|------|--------|
| 0～27 | 孢子 |
| 28～54 | 原丝体 |
| 55～79 | 小芽 |
| 80～99 | 长大 |
| 100 | 成熟 |

成熟后会弹窗，并把种类 ID 放进 **collection**（图鉴数组）。

---

## 7. 地钱类 vs 藓类：数据和画法

- **数据**：`species.js` 里 `group: 'liverwort'` 是地钱类（扁叶），`'moss'` 是藓类（小茎叶）。  
- **3D 主视图**：`plant3d.js` 里 `buildLiverwort()` 从**一小坨幼叶**长成**二叉扁带**，成熟加胞芽杯 / 掌形雌托；`buildMossCushion()` 从 **5～6 个小茎**长成**厚垫**，成熟加 seta 和孢蒴（葫芦藓是弯柄 + 葫芦形蒴）。  
- **2D 备用**：`draw.js` 在 WebGL 失败时仍可用。

---

## 8. 存档怎么工作？

- 键名：`gugeegoo_plant_save`（见 `constants.js`）  
- `buildSavePayload()` 打包：当前植物 + 图鉴列表 + 时间  
- 关页 / 隐藏标签 / 定时 → `writeSave()`  
- 再打开 → `readSave()`，并用 `applyOfflineDrain()` 补算离线时间，**最多 30 分钟**（`OFFLINE_DRAIN_CAP_MS`），避免上学一天回来全枯了  

坏档或没有存档 → 当作新游戏，不会报错卡死。

## 9. 动手试一试

1. **改成长速度**：打开 `constants.js`，把 `GROWTH_PER_SEC_HEALTHY` 改成 `0.25`，重新 build，看看是不是更快成熟。  
2. **加一种新苔藓**：在 `species.js` 的数组里复制一项，改 `id` 和 `ideals`；在 `draw.js` 里可以不改（会用藓类画法），或加 `if (id === 'xxx')` 画特殊形状。  
3. **加新动作**：在 `growth.js` 的 `applyCareAction` 里加一种 `action`，在 `index.html` 和 `main.js` 里加按钮。  
4. **跑自动测试**：在项目根目录执行 `npm run validate:plant`，看七种苔藓能不能在理想照顾下成熟、在 neglect 下枯萎。

## 10. 3D 是怎么工作的？（简单版）

1. **懒加载**：`main.js` 里的 `initPlant3d()` 用 `import('./plant3d.js')` 和 `import('three')`，只有打开养植物页才下载 Three.js。  
2. **场景 (scene)**：像一个小舞台，里面有光、相机、花盆模型、苔藓模型。  
3. **相机 (camera)**：你的「眼睛」，从斜上方看向花盆。  
4. **渲染器 (renderer)**：把 3D 画到 `<canvas>` 上；像素比最多 **2**，省 iPad 电。  
5. **OrbitControls**：手指拖动旋转；双指缩放；**不能平移**；停手几秒后会慢慢自转。  
6. **成长怎么变形状**：`view.update(种类, growth, mood)` 根据 `growth` 0～100 调用 `buildLiverwort` 或 `buildMossCushion`，用低多边形方块、圆柱拼出来；`mood` 会让颜色变黄/变褐，并稍微「低头」。  
7. **标签页隐藏**时停止 `requestAnimationFrame`，回来再继续画。  
8. **失败怎么办**：`createPlant3dView` 返回 `ok: false` 时，页面继续用 `draw.js` 的 SVG。

小练习：在 `plant3d.js` 里找到 `autoRotateSpeed`，改大一点，看看自转是不是更快。

## 11. 成熟以后还会长吗？

**不会。** 一旦 `status` 变成 `'mature'`（`growth` 到 100），`displayGrowth()` 和 3D 模型都**锁在满尺寸**，`tickMaturePlant()` 里 **`growth` 永远是 100**。

成熟后的规则（代码在 `growth.js` + `constants.js`）：

| 项目 | 行为 |
|------|------|
| 水分 / 养分 | 用 **`MATURE_DRAIN_PER_SEC`** 慢慢下降（比小时候慢） |
| 阳光 | **不再下降**；条上显示「够用」；`assessCare(..., { mature: true })` **不检查阳光** |
| 晒太阳按钮 | 还能点，只提示「长大啦…」；**不会晒坏** |
| 健康 | 只看出水、肥； neglect 太久仍会 **`withered`** |
| 提示语 | `MATURE_CARE_MESSAGE`：「长大啦！以后每天记得浇水、施肥就好」 |

`main.js` 里成熟后**不会禁用**浇水和施肥按钮（只有枯萎才全禁）。

## 12. 和测试脚本的关系

`scripts/validate-plant.mjs` **不打开浏览器**，直接 import `growth.js` 和 `storage.js`：

- 对每种苔藓模拟最多 900 秒 + `autoIdealCare` → 必须 `mature`  
- 再用 `simulateSecondsMature`：体型不变、阳光不变、水分要下降  
- 成熟 neglect（约 **1100** 秒，因 `MATURE_DRAIN_PER_SEC` 较慢）→ 必须 `withered`；`autoMatureCare` 则保持活着  
- 最后测一遍存盘读盘  

这样改规则后，跑一条命令就能知道有没有改坏。
