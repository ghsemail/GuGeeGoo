## 第 1 题　（W1-Day1-1）

**a 列 · 化简后的比：1 : 2 · 比值：$\frac{1}{2}$**

**c 列 · 化简后的比：7 : 10 · 比值：$\frac{7}{10}$**

解析：
- 0.18 : 0.36 → 18 : 36 → **1 : 2**，比值 **$\frac{1}{2}$**
- 0.35 : $\frac{1}{2} = \frac{7}{20} : \frac{10}{20}$ → **7 : 10**，比值 **$\frac{7}{10}$**

### 易错提醒

- 与第 1 题原题相同结构：先化简再求比值；小数与分数混合先统一形式。

## 第 2 题　（W1-Day1-3）

**答：6**

解析：
- 前两项互为倒数，$x^2 = 9$ → x = 3，前两项 **3 : $\frac{1}{3}$**
- 内项积 9 → $\frac{1}{3} \times m = 9$ → m = 27
- 外项积 9 → $3 \times n = 9$ → n = 3
- 外项之和 **3 + 3 = 6**

验证：内项积 $\frac{1}{3} \times 27 = 9$ ✓；比值 $3 \div \frac{1}{3} = 9$ ✓

## 第 3 题　（W1-Day2-4）

**答：C**

解析：
- C：$\frac{1}{3} : \frac{1}{5} = 10 : 6$
- 内项积：$\frac{1}{3} \times 6 = 2$；外项积：$\frac{1}{5} \times 10 = 2$ ✓

### 易错提醒

- 组成比例后要用内项积 = 外项积验算。

## 第 4 题　（W1-Day3-8）

**答：$\frac{89}{90}$**

解析：
- $88\frac{88}{89} = \frac{88 \times 89 + 88}{89} = \frac{88 \times 90}{89}$
- 比值 = $88 \div \frac{88 \times 90}{89} =$ **$\frac{89}{90}$**

## 第 5 题　（W1-Day3-9）

**答：36 : 15 : 10**

解析：
- 设左侧阴影面积为 12
- 圆 = $12 \div \frac{1}{6} =$ **72**；长方形 = $12 \div \frac{2}{5} =$ **30**
- 右侧阴影 = $30 \times \frac{1}{6} =$ **5**；大三角形 = $5 \div \frac{1}{4} =$ **20**
- 72 : 30 : 20 同除以 2 → **36 : 15 : 10**

验证：$\frac{12}{72}=\frac{1}{6}$ ✓；$\frac{12}{30}=\frac{2}{5}$ ✓；$\frac{5}{20}=\frac{1}{4}$ ✓；$\frac{5}{30}=\frac{1}{6}$ ✓

## 第 6 题　（W1-Day4-10）

**答：5 : 4**

解析：
- 长方形周长 = $2 \times (b+3b) =$ **8b**
- 正五边形周长 = **5d**
- $8b = 2 \times 5d = 10d$ → b : d = **5 : 4**

---

## 第 7 题　（W1-Day4-11）

**答：3 : 5**

解析：
- a : b = $\frac{5}{3} : 1.5 = 10 : 9$
- b : c = 0.9 : 0.6 = 3 : 2 → 统一 b：a : b : c = 10 : 9 : 6
- c : a = **6 : 10 = 3 : 5**

---

## 第 8 题　（W1-Day4-12）

**答：6 : 3 : 2**

解析：
- $\frac{\text{甲}}{3} = 4\text{乙} = \frac{\text{丙}}{2} = k$ → 甲=3k，乙=$\frac{k}{4}$，丙=2k
- $\frac{\text{甲}}{2} = \frac{3k}{2}$；$3\text{乙} = \frac{3k}{4}$；$\frac{\text{丙}}{4} = \frac{k}{2}$
- $\frac{3k}{2} : \frac{3k}{4} : \frac{k}{2}$ → 同乘 $\frac{4}{k}$ → **6 : 3 : 2**
